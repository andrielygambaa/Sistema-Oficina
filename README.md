# 🔧 Sistema de Gerenciamento de Oficina

Bem-vindo ao projeto Sistema de Gerenciamento de Oficina!

Este sistema foi desenvolvido com o objetivo de auxiliar oficinas mecânicas no controle e organização de serviços, clientes e veículos.

## ⚙️ Funcionalidades

O sistema permite:

- Cadastro de clientes
- Cadastro de veículos
- Registro de serviços realizados
- Controle de ordens de serviço
- Histórico de manutenções
- Controle de status (em andamento, concluído, aguardando peças)

## 🎯 Objetivo

Facilitar a gestão de oficinas mecânicas através de uma aplicação simples, eficiente e organizada.

## 💻 Tecnologias Utilizadas

- HTML
- CSS
- JavaScript
- Banco de Dados
